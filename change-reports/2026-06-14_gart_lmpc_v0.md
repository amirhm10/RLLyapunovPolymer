# GART-LMPC v0 Implementation

## Summary

Added a new parallel Governed Artificial-Reachable-Target Lyapunov MPC path for the Polymer CSTR study. The implementation leaves the existing direct target selector defaults unchanged and introduces nominal smoke experiments with five short episodes for initial validation.

## Changes

- Added `Lyapunov/gart_target.py` with certified disturbance filtering, lexicographic closest-reachable target selection, target-motion constraints, terminal input tightening, contraction probing, and governed-reference fallback.
- Added `Lyapunov/gart_lmpc.py` with a mixed raw-setpoint plus target-centered Lyapunov MPC step solver.
- Added `utils/gart_defaults.py` for case-value discovery, default config builders, and a future GART RL observation helper.
- Added `experiments/run_gart_target_selector_study.py` for target-only and closed-loop nominal smoke studies.
- Added `analysis/gart_target_selector_analysis.py` for post-run summaries and compact plots.
- Added `report/gart_lmpc_design_notes.md` documenting the method and practical-stability bookkeeping.

## Validation Plan

The low-cost validation for this change is:

```powershell
python -m py_compile Lyapunov/gart_target.py Lyapunov/gart_lmpc.py utils/gart_defaults.py experiments/run_gart_target_selector_study.py analysis/gart_target_selector_analysis.py
pytest tests/test_gart_target.py
python experiments/run_gart_target_selector_study.py --mode nominal --n-tests 5 --set-points-len 20 --target-only --closed-loop
```

The smoke experiment is intentionally nominal with `disturbance_after_step=False` so it checks target/MPC wiring before long disturbed comparisons.
