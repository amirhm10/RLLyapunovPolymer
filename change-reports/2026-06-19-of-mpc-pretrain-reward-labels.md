# OF-MPC Pretraining Reward Labels Use Online TD3 Weights

## Summary
- Separated OF-MPC controller objective weights from TD3 offline reward-label weights.
- Kept OF-MPC action generation unchanged:
  - `Q_MPC = [5, 1]`
  - `R_MPC = [1, 1]`
- Changed future OF-MPC TD3 replay-buffer reward labels to use the online TD3 quadratic reward weights:
  - `Q_REWARD_DIAG = [12, 6]`
  - `R_REWARD_DIAG = [1, 1]`

## Rationale
The offline OF-MPC pretraining buffer uses one-step quadratic reward labels in scaled deviation coordinates:

$$
r_k = -\left((y_{k+1} - y_{\mathrm{sp}})^T Q_{\mathrm{reward}} (y_{k+1} - y_{\mathrm{sp}})
      + \Delta u_k^T R_{\mathrm{reward}} \Delta u_k\right).
$$

These labels train the TD3 critic, but they do not define the OF-MPC optimization problem used to generate the teacher action. Keeping the MPC objective at `[5, 1]` and `[1, 1]` avoids changing the teacher controller, while using `[12, 6]` and `[1, 1]` for reward labels aligns the pretrained critic with the online TD3 reward scale.

## Files Changed
- `utils/of_mpc_td3_workflow.py`
  - Added explicit `Q_REWARD_DIAG` and `R_REWARD_DIAG` constants.
  - Derived replay-buffer reward matrices from those reward constants.
  - Recorded both reward diagonal vectors and reward matrices in future pretraining configs.
  - Updated the pretrained OF-MPC comparison reward helper to use reward-label weights, not MPC objective weights.
